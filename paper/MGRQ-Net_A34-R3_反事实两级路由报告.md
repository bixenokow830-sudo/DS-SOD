# MGRQ-Net A34-R3 反事实两级路由实验报告

## 1. 阶段结论

A34-R3 已完成 10540 个反事实训练样本、训练内阈值校准和 400 张严格内部验证。工程状态为 **PASSED**，研究验收门为 **FAILED**，DeepSeek API 调用为 0。

与 A34、A34-R1、A34-R2 相比，A34-R3 首次同时实现了以下结果：

- 干净集 Macro S 相对 A33-R1 提高 0.001019。
- 干净集 Macro MAE 仅增加 0.000098。
- 删除 30% 正确候选时，组件召回提高 0.029542。
- 删除 30% 正确候选时，Macro S 提高 0.015123，Macro MAE 降低 0.002651。
- 干净集发现路由启用率降至 12.75%。
- 无 MLLM 时仍保留 0.353028 的发现查询召回。

研究门仅剩一项未通过：在干净集被路由的 51 张图中，有 28 个被选发现查询重复覆盖了 MLLM 已覆盖组件，条件重复率为 54.90%。不过，由于路由器只在 12.75% 的干净图上启用发现分支，重复选择占全部验证图的比例为 7%，且最终 S、MAE 均未表现出显著副作用。

因此，A34-R3 已经形成可用的总体架构，下一步只需在查询选择端加入显式新颖性约束，不需要重新训练底座、发现查询或图像路由器。

## 3. 路由校准结果

训练内校准集在阈值 0.35 时达到：

- 干净输入启用率：14.68%。
- 反事实可恢复漏检召回率：97.82%。
- 反事实真阳性：224。
- 反事实假阴性：5。

与 A34-R2 的阈值 0.05、精确率 1.02% 相比，反事实训练显著改善了图像级缺失状态的可分性。验证集路由分布也符合预期：

- 干净集启用率：12.75%，51/400。
- 删除 30% 正确候选后启用率：25.75%，103/400。
- 无 MLLM 候选时：强制启用。

这说明路由器确实对候选缺失敏感，而不是固定地在所有图像上开启发现分支。

## 7. 剩余问题的准确解释

### 7.1 图像路由已经有效，查询排序仍偏向已有显著对象

图像路由器能识别候选缺失风险，但查询排序器仍倾向选择响应最强、同时也是最可能与 MLLM 重叠的发现查询。干净集 51 个被选查询中：

- 重复查询：28。
- 假选择：16。
- 其余非重复且非明显假选择：7。

### 7.2 条件重复率高，但全局副作用已较小

54.90% 是“已启用查询中的重复比例”，不是所有图像上的重复比例。重复启用只发生在 28/400 张图上，占 7%。这解释了为何条件重复率未通过，但整体 S 提升且 MAE 几乎不变。

### 7.3 当前验收门仍有必要保留

即使全局指标良好，若论文宣称发现查询用于补漏，干净集被启用的查询却多数重复已有对象，机制解释会受到质疑。因此不建议简单删除重复率验收项，而应进一步修正查询效用排序。

## 8. 建议执行 A34-R4：新颖性否决与效用重排

A34-R4 不需要重新训练图像路由器或发现查询，只在严格训练内校准集上确定查询选择规则。

### 8.1 查询效用分数

将查询选择从单一学习分数改为：

```text
utility(q) = query_score(q)
             + λ × novelty(q)
             - μ × overlap(q, M_mllm)
```

由于 `novelty = 1 - overlap`，实现时只需一个等价权重。建议在训练内校准集网格搜索 `λ∈{0,0.25,0.5,1,2}`。

### 8.2 显式重叠否决

若候选查询与 MLLM 联合掩码的软 IoU 高于训练内校准阈值 `τ_overlap`，直接不启用该查询。`τ_overlap` 仅从训练内校准集选择，目标约束为：

- 干净配对条件重复率低于 20%。
- 反事实删除配对的可恢复组件召回最大。
- 若没有规则满足约束，阶段直接失败，不允许回退到无否决选择。

### 8.3 保持不变的部分

- 保留 A34-R3 图像路由器、阈值 0.35 和无 MLLM 强制兜底。
- 保留 A34 原始发现查询。
- 不再训练神经网络参数。
- dev 只进行一次最终评价。

### 8.4 A34-R4 验收条件

- 沿用 A34-R3 的全部验收门。
- 条件重复率必须低于 20%。
- 干净集路由后实际选择率低于 15%。
- 删除 30% 正确候选时组件召回增益不低于 0.02。
- 干净集 S 和 MAE不得劣于 A33-R1 的既定容限。

## 9. 阶段决策

A34-R3 已达到可用模型水平，但尚未达到机制解释完全闭合的研究标准。推荐：

**执行 A34-R4，只校准新颖性重排和重叠否决，不再重新训练模型。若 A34-R4 无法在保留补漏增益的同时降低条件重复率，则停止 A34 系列修复，并以 A34-R3 作为性能最优的候选版本、A33-R1 作为保守基线。**
