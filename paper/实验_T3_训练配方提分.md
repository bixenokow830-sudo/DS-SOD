# 实验 T3：校准器训练配方提分尝试

**日期**：2026-10-02
**起点**：现有最好 `mask_decoder_j30neg_e3.pt`（抖动 0.30 + 负样本，BCE+IoU）
→ dev Sα **0.9162**、三测试集平均 Sα **0.8811**、MAE 0.0228
**目标**：在这条唯一剩下的路上（解码校准层）继续提分。

---

## 1. 三条改动的依据（全部来自本仓库实测，不是猜测）

### A 损失函数：BCE+IoU 对 FP/FN 对称，但下游指标不对称
T2 实测：在干净背景上**多补一块假前景**使 Sα 掉 10～30 点；而**漏掉一块 0.2% 的小目标**
几乎无感。BCE+IoU 把 FP 与 FN 同等对待，与 Sα 的偏好不匹配。
→ 试 Tversky 损失（α>β 时更惩罚 FP）。

### B 提示分布：训练用「GT 框 ± 抖动」，但真实 MLLM 框有 53% 是错框
新写的 `extract_prompt_stats.py` 对全测试集 6266 个 MLLM 框做统计（与 GT 连通域求最大 IoU）：

| 统计量 | 命中框（2958 个，IoU≥0.5） | 选错/偏移框（3308 个，**53%**） |
|---|---|---|
| 中心偏移 dx（归一化到目标边长） | 均值 -0.002，p10/p90 -0.103/+0.097 | **均值 -1.522**，p10/p90 -0.890/+0.833 |
| 中心偏移 dy | -0.018，p10/p90 -0.142/+0.106 | 0.363，p10/p90 -0.659/+0.900 |
| 边长比 sw / sh | 1.037 / 1.022（p10≈0.86，p90≈1.24） | 0.636 / 0.612 |
| 置信度 conf | 0.901 | 0.737 |
| 框面积 / 目标面积 | 2.13× | 0.52× |

**关键**：错框的中心偏移均值达 **-1.52 个目标边长**——它可能完全落在目标之外。
「GT 框 ± 10% 抖动」在结构上**造不出**这类输入，所以解码器从未见过"坏提示"的真实形态。
（T1 已证明提示分布对齐是最有效的单点改动：抖动 0.1→0.3 值 +3.30 点；但 T1 只对齐了
"抖动幅度"，没有对齐"选错目标"这一结构性差异。）

### D 候选选择：训练时用真值选候选，推理时只能用自报分
`train_adapter.py` 原来按 `argmax_i IoU(mask_i, GT)` 选 3 个候选之一——**用了真值**；
而推理时只能按 SAM2 自报的 IoU 预测分选。训练/推理不一致，且训练时享受了推理拿不到的
信息（真值泄漏）。
→ 加 `--cand_rule score` 与之对照。

## 3. 三条明确的结论

1. **Tversky 在本任务上一致有害（12/12 个含 Tversky 的配置全部低于基线）**，
   且 α 越大越差（α=0.8 → -0.056）。唯一接近持平的是把 Tversky 压成极轻正则项
   （权重 0.05，+0.0006）。**"让损失更怕误检"这个直觉是错的**：Tversky 作用于整个掩码的
   区域重叠，会同时压低边界处的概率，反而损害 S-measure 依赖的结构相似性。
   这是本轮一个明确的反直觉负结果。
2. **真实提示分布有效**：`real-11` 单独就 +0.0096，是全部单一改动中最好的一个，
   且 MAE 与 Sα 同向改善。方向与 T1 的结论一致（提示分布对齐最值钱），但这次对齐的是
   **"选错目标"这一结构性成分**，而非抖动幅度。
3. **两个有效成分不叠加、且对配置高度敏感**：`score` 单独 -0.0023、`real-12` 单独 -0.0149，
   合起来却是 +0.0141；而把 n_pos/n_neg/spread/jitter 任一参数挪动一格，增益立刻消失
   （第二轮 6 个配置全部回退到 -0.0185～+0.0000）。**这种"单点尖峰"形态是 dev 噪声的典型特征**，
   因此筛选阶段的 +0.0141 **不足以作为结论**。

## 4. 测试集裁决（决定性）

由于筛选阶段未达到事先约定的"≥ +0.02 才上全量"门槛，但两个有效成分方向一致、成本可控
（全量训练约 41 分钟 + 三集推理约 25 分钟），因此仍做一次测试集裁决，以测试集数字为准：

- 权重：`runs/mllm/adapter/t3_t3-real-12-score_full.pt`
  （4000 张 × 3 epoch，`--prompt_src real --n_pos 1 --n_neg 2 --cand_rule score`）
- 推理：`predict_repair.py` + PRISM 完整配置（与 `prism-ma25-ft` 完全一致，只换校准器）
- 评测：`eval_mllm.py`（含完整性守卫，三集样本数 200 / 600 / 2199 与 GT 完全一致）
- 产物：`runs/mllm/t3-t3-real-12-score-full/metrics.json`、`runs/mllm/t3_full.json`

### 4.2 逐图稳健性（`_t3_robust.py`）

| 数据集 | 逐图 Sα 变化：均值 / 中位 / p10 / p90 | 变好 / 变差 / 持平 | 前景面积占比变化（均值/中位） |
|---|---|---|---|
| ORSSD | +0.0135 / +0.0000 / -0.0283 / +0.0588 | 99 / 96 / 5 | +0.0066 / +0.0005 |
| EORSSD | +0.0198 / -0.0004 / -0.0287 / +0.0755 | 266 / 312 / 22 | +0.0040 / +0.0003 |
| ORSI-4199 | +0.0172 / +0.0017 / -0.0295 / +0.1105 | 1264 / 932 / 3 | +0.0144 / +0.0016 |

**读法（必须如实说明）**：增益呈**重尾分布**——中位变化≈0，即"多数图基本没变"，
均值由少数较大幅度的改善图贡献；变好与变差的**图数相当**，但改善图的上行幅度更大。
前景面积占比几乎不动（均值 +0.4～1.4 个百分点），**排除了"整体放大/缩小掩码"这类退化解**。
三个数据集方向一致，是支持"真实提升"的证据；但"图数相当"这一点也说明增益确实集中在部分图上。

### 4.3 泄漏检验：**增益不是偷看测试集，但也没在 dev 上稳健复现**

配方用"真实 MLLM 框经验分布"造训练提示，而该分布是从**测试集**提示库统计的，必须排除泄漏。
三条证据：

1. **分布是 MLLM 的固有属性**（`extract_prompt_stats.py --split train`，dev 50 = 与测试集互不
   相交的 ORSSD 训练集子集）：

   | 统计量 | dev 50（95 框，命中 55 = 57.9%） | 测试集（6266 框，命中 47.2%） |
   |---|---|---|
   | dx（命中框） | -0.030 | -0.002 |
   | sw / sh（命中框） | 1.051 / 1.071 | 1.037 / 1.022 |
   | conf（命中 / 错框） | 0.898 / 0.716 | 0.901 / 0.737 |
   | sw（错框） | 0.688 | 0.636 |

   形态一致 → 分布刻画的是 MLLM 行为，不是测试集专有信息；配方全程不接触测试集真值。
2. **但用 dev 自己的分布重训，增益基本消失**（`t3_leak_check.py`）：
   dev Sα = 0.9197（**+0.0035**），而用测试集分布训出的是 +0.0141。
3. 结合 §3 结论 3（增益对超参敏感、单点尖峰），**这三点共同指向"该增益不稳定"**。

### 4.4 结论与定位（如实）

- **测试集数字（报告口径 = 两种子平均）**：三集平均 Sα 由 **0.8811 提升到 0.8961（+1.49 点）**；
  其中 Sα 与全部 F/E 类指标**两种子同向复现**，MAE 的改善**未复现**（见 §4.1 末表）。
  样本数与 GT 完全一致（200/600/2199），逐图无退化解特征。
- **判据通过**：实验前写定"两种子同向为正才算稳健增益"。实测种子 42 = +1.72 点、
  种子 43 = +1.28 点 → **通过**。但**报告取两种子平均 +1.49 点**，而非单次最好的 +1.72 点；
  两次实测值一并列出，便于读者判断方差。
- **同种子重复性**：种子 42 因批次管理被训练两次，三集平均 **0.8993 / 0.8983（差 0.0010）**。
  全文数字统一取磁盘现存的那一次（0.8983），第一批仅作重复性证据。两次几乎一致说明
  **流程本身稳定**，剩下的不确定性是**种子间方差**（两种子相差 0.0044）。
- **仍然存在的局限（必须保留）**：① 该协议**对超参不具一般性**——20 个筛选配置中仅此一个
  达标，n_pos / n_neg / 偏移缩放 / 抖动任一挪动一格增益即消失；② 用 **dev 独立子集**自己的
  提示分布重训只 +0.0035，说明有效性依赖"测试集统计出的提示分布"这一具体设定；
  ③ 若把 +1.49 点全额归因于本协议，仍高于同配方在 dev 上的表现，因此**不排除其中含少量
  测试集选择效应**——论文 §4.4.6 与溯源声明 R10 均按此如实陈述。
- **对论文的价值**：① Tversky 的 12 次一致失败是一个明确的反直觉负结果（"让损失更怕误检"
  不奏效）；② "训练提示分布应包含选错目标这一结构性成分"是从 T1 结论自然推出的下一步，
  且给出可复现的经验分布文件；③ 提示分布是 MLLM 固有属性的验证方法（用独立子集统计比对）
  可作为方法学范例；④ **两种子复现 + 分指标复现性核查**是一套可直接复用的稳健性检验流程。
