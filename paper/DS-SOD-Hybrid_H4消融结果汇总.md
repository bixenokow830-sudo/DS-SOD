# DS-SOD-Hybrid 消融与附加实验结果汇总（H4）

> 主方法：DS-SOD-Hybrid = 冻结 SAM2 base+（MLLM 语义框提示）+ 轻量适配器（仅微调 mask decoder 4.22M）
> 数据：ORSSD(200)/EORSSD(600)/ORSI-4199(2199) 测试集，指标 Sα/MAE

## 表 A：提示来源消融（同适配器，三测试集 Sα / MAE）

| 数据集 | 随机框（无语义） | MLLM 框（本文） | GT 框（上界） |
|--------|----------------|----------------|--------------|
| ORSSD | 0.704 / 0.108 | **0.865 / 0.033** | 0.933 / 0.010 |
| EORSSD | 0.640 / 0.122 | **0.853 / 0.022** | 0.926 / 0.006 |
| ORSI-4199 | 0.659 / 0.129 | **0.799 / 0.058** | 0.862 / 0.038 |

结论：MLLM 语义提示贡献 **+16～21pt Sα**；MLLM→GT 剩余 7～10pt 为提示精度空间；
GT→SOTA（IPDiff 0.891～0.956）剩余 3～7pt 为"冻结 SAM2+适配器"的范式上限。

## 表 B：提示形式消融（dev 50，均配适配器）

| 提示形式 | Sα | MAE | 结论 |
|---------|-----|-----|------|
| box（主线） | 0.8865 | 0.0216 | 最优 |
| mask（多边形栅格） | 0.6359 | 0.1588 | 硬掩码有害（过度信任粗糙草稿） |
| mask + box | 0.8850 | 0.0255 | 持平 |
| box + 顶点点 | 0.8903 | 0.0255 | +0.4pt（噪音级） |

结论：MLLM 多边形（平均 10 顶点）过粗糙，形状信息无法有效注入 SAM2；
box 提示已是提示形式的最优解。

## 表 C：场景分组（Sα，全测试集；每图可属多组）

| 场景 | 图数 | Hybrid-Adapter | Zero(纯几何) | 增益 |
|------|------|---------------|-------------|------|
| none | 112 | **0.868** | 0.725 | +14.3 |
| large_object | 1528 | **0.837** | 0.660 | +17.7 |
| shadow | 404 | **0.819** | 0.662 | +15.7 |
| low_contrast | 604 | 0.804 | 0.647 | +15.7 |
| similar_spectrum | 749 | 0.800 | 0.629 | +17.1 |
| multiple_objects | 1285 | 0.789 | 0.644 | +14.5 |
| small_object | 1445 | 0.786 | 0.651 | +13.5 |
| clutter | 363 | **0.785** | 0.624 | +16.1 |

结论：全场景普适提升 13～18pt；短板在 clutter/small_object/multiple_objects；
低对比与同谱异物（传统语义难例）反而表现好（0.80）——MLLM 语义起作用。

## 表 D：失败分析（Hybrid-Adapter，全测试集按类别平均 MAE）

| 类别 | 图数 | 平均 MAE | 难易 |
|------|------|---------|------|
| playground | 252 | 0.148 | 最难（大而不规则区域） |
| tree | 249 | 0.104 | 成簇、边界模糊 |
| bridge | 240 | 0.097 | 细长结构 |
| harbor | 26 | 0.092 | |
| building | 923 | 0.082 | 大建筑+阴影 |
| vehicle | 863 | 0.055 | |
| storage tank | 261 | 0.048 | |
| river | 303 | 0.034 | |
| island | 61 | 0.032 | |
| ship | 436 | **0.022** | 易（紧凑刚体） |
| airplane | 436 | **0.022** | 易（紧凑刚体） |

最差 30 张归因：类别 bridge×14 / building×14 / vehicle×13；
难例标签 large_object×23 / multiple_objects×14 / small_object×12。
→ 失败模式 = **大而复杂区域（操场/建筑群）+ 细长结构（桥）+ 成簇小目标**；
成功模式 = **紧凑刚体（船/飞机/车辆/储罐）**。
