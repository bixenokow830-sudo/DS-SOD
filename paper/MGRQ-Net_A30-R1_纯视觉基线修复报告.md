# MGRQ-Net A30-R1｜纯视觉查询基线修复报告

## 1. 执行结论

A30-R1已完成并通过工程与修复效果验收。该实验保持A30的纯视觉定义、模型容量、随机种子和严格数据协议不变，只修复训练目标与最终显著图输出不一致的问题：在组件匹配损失之外，增加5个查询最大值并集对完整GT的BCE+Dice监督，并将未匹配查询背景BCE权重由0.1提高到0.5。

修复后严格dev宏平均Sα由0.6818提高到0.8131，提升0.1312；MAE由0.0938降低到0.0373，下降0.0564。400/400张预测完整，检查点全部有限，没有使用DeepSeek提示或官方测试集。

阶段门禁由A30的`NO-GO_A31`更新为`GO_A31_WITH_RECORDED_GAP`。A30-R1仍低于M04严格监督基线，但已具备稳定、可解释且明显更强的纯视觉对照。A31必须以A30-R1为实际比较基线，而不是原始A30。

## 2. 唯一方法改动

A30推理使用5个查询概率逐像素最大值得到最终显著图：

```text
S(x,y) = max_i sigmoid(M_i(x,y))
```

原训练只监督匈牙利匹配后的单组件掩码，没有直接约束`S`。A30-R1新增：

```text
L_union = BCE(S, GT_union) + Dice(S, GT_union)
L_total = L_component + 0.5 L_unmatched-bg + L_union
```

其中`GT_union`来自I20完整组件标签并集，包含每图全部组件，不受最多5个组件匹配槽限制。模型结构、查询数量和推理方式均未改变。

完整GT并集监督不仅改善普通图像，也显著修复了空GT假阳性和超过5组件时的监督截断影响。密集组件仍只有6张，适合诊断，不适合据此声称统计显著性。

## 8. 剩余差距与解释边界

A30-R1与M04相比仍有7.89个Sα百分点差距，说明纯视觉学习查询尚不能替代高质量几何提示。当前结果只支持以下结论：

- 训练目标对齐是必要修复，并带来跨数据集一致提升；
- 冻结SAM2特征加查询解码器能够形成可用纯视觉基线；
- 剩余差距可由A31检验DeepSeek几何候选是否能够缩小。

不能把A30-R1描述为接近主流监督方法，也不能用本次结果预设文本语义或可靠性模块一定有效。
