# MGRQ-Net I26｜发现查询、适配器与细化模块单测报告

## 1. 执行结论

I26 已完成并通过验收（`PASSED`）。本阶段实现并独立验证了三个待用于主消融的模块：5个可学习发现查询、零初始化残差瓶颈适配器，以及基于粗掩码池化的两阶段查询—掩码细化模块。

专项单元测试10/10通过，联合验收9/9通过。关闭MLLM候选后，发现查询仍能独立完成前向；适配器初始化时与恒等映射逐元素完全一致；全空掩码池化输出严格为零且没有NaN或Inf；模拟优化步骤中冻结主干无梯度、权重不变，只有指定适配器参数发生更新。

I26没有启动正式数据集训练，因此不产生显著性指标，也不作为模块有效性的性能证据。各模块的真实增益将在A30–A36递增消融中分别验证。

## 2. 发现查询

| 项目 | 设置 |
|---|---|
| 查询数量 | 5 |
| 查询维度 | 256 |
| 初始化 | 正态分布，标准差0.02 |
| 可训练参数 | 1,280 |
| 有MLLM候选 | 追加到MLLM查询之后 |
| 无MLLM候选 | 单独构成5个有效查询 |

模块同时返回有效性掩码和查询来源掩码，便于后续A34分别统计MLLM查询与发现查询的匹配率、组件召回率和重复预测。

在关闭MLLM的联合验收中，发现查询形状为`[2,5,256]`；输入基础解码器后输出掩码形状为`[2,5,8,8]`，全部数值有限。

## 3. SAM2后层残差适配器

适配器采用二维瓶颈残差结构：

```text
x' = x + Conv1×1_up(DWConv3×3(GELU(Conv1×1_down(x))))
```

| 项目 | 设置 |
|---|---|
| 输入/输出通道 | 256 |
| 瓶颈通道 | 64 |
| 空间算子 | 3×3深度卷积 |
| 可训练参数 | 33,728 |
| 上投影初始化 | 权重与偏置均为0 |
| 初始化最大绝对误差 | 0.0 |

上投影零初始化保证模块插入已训练视觉主干时，初始前向严格不改变原特征，避免尚未训练的适配器立即破坏SAM2表示。`freeze_except_adapters`工具会先冻结宿主网络，再只开启适配器参数。

模拟一步优化后：

- 冻结主干权重逐元素不变；
- 冻结主干参数没有梯度；
- 适配器参数发生更新；
- 实际启用6个适配器参数张量。

## 4. 两阶段查询—掩码细化

第一阶段粗掩码经Sigmoid转换为软权重，用它对图像特征进行查询级加权池化。池化特征与第一阶段查询拼接，经残差更新生成细化查询，再与投影后的像素特征点积得到第二阶段掩码。

| 项目 | 设置 |
|---|---|
| 查询/特征维度 | 256 |
| 更新隐藏维度 | 512 |
| 可训练参数 | 592,896 |
| 池化 | 软掩码加权平均 |
| 空掩码策略 | 分母阈值判断后显式返回零向量 |
| 无效查询 | 查询置零，掩码logit固定为-20 |

联合验收使用全`-100`粗掩码logit模拟空掩码，池化特征最大绝对值为0.0，第二阶段输出`[2,5,8,8]`且全部有限。
