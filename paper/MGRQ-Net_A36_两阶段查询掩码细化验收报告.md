# MGRQ-Net A36 两阶段查询—掩码细化验收报告

## 1. 阶段结论

A36 已完成 `seed=42` 的严格训练、400 张内部验证、边界质量评测和结构子集评测。工程状态为 **PASSED**，研究验收门为 **FAILED**，DeepSeek API 调用为 **0**。

两阶段细化器仅增加约 1.52 ms/图的前向耗时，计算成本可接受；但整体边界 F 从 0.622209 降到 0.489582，下降 0.132627，同时 MAE 增加 0.001117，F_mean 和 E_mean 也分别下降 0.009814 和 0.012265。细长目标子集的 Sα 虽提高 0.002570，但边界 F 下降 0.083112，不能构成有效的结构改进。

因此 A36 不进入最终模型，不建议继续 A36 修复。后续 A37 应对当前最佳配置 **A34-R4** 补做随机种子确认。

## 3. 冻结评测口径

为避免只看整体显著性分数掩盖结构退化，本阶段在训练前固定以下统计规则：

- 边界 F：预测和真值均以 0.5 二值化，匹配容差为图像对角线的 0.75%；
- 小目标子集：图像中至少包含一个面积不超过全图 1% 的显著组件；
- 细长目标子集：图像中至少包含一个长宽比不小于 4，或组件面积/外接框面积不大于 0.35 的显著组件；
- A34-R4 基线与 A36 使用完全相同的 400 张图像、预测文件和统计函数。

本报告的整体与子集值采用“逐图汇总”口径，因此 A34-R4 的整体 Sα 为 0.837633；此前 A34-R4 报告中的 0.836176 是“三数据集等权宏平均”。两者聚合权重不同，不能直接混用；本阶段的所有差值均使用同一逐图口径计算。

## 7. 验收门

| 条件 | 结果 |
|---|---|
| 训练张量有限 | 通过 |
| 400 张验证预测完整 | 通过 |
| 整体 Sα 下降不超过 0.001 | 通过（−0.000960） |
| 整体 MAE 增加不超过 0.001 | **失败（+0.001117）** |

八项条件中三项失败，研究门为 `FAILED`。

## 8. 原因判断

1. 细化器以粗掩码概率作为池化权重，粗掩码边界误差会直接污染第二阶段查询更新。
2. 当前损失以组件 BCE、Dice 和显著区域并集为主，没有显式边界或拓扑监督；损失下降不能保证边界 F 提升。
3. 第二阶段重新生成完整掩码，而不是只预测边界残差，容易覆盖第一阶段已经较好的轮廓。
4. A34-R4 的路由和选择规则在粗掩码上校准，细化后掩码分布发生变化，但本阶段按预注册方案没有重新校准规则。
5. 小目标和细长目标上的 Sα 小幅提升不足以抵消明显的边界与 MAE 退化。

## 9. 阶段决策与下一步

A36 到此结束：

- 不将 A36 细化器纳入最终 MGRQ-Net；
- 不以 A36 检查点继续 A37；
- 保留 A36 作为“二阶段细化未通过边界验收”的负结果；
- 最终候选仍为 A34-R4；
- 下一阶段按计划执行 A37，用 seed 43 验证 A34-R4 的增益方向是否稳定。
