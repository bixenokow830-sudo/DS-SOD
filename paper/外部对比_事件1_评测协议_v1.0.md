## 1. 比较要回答的问题

核心比较只回答一个问题：**在不使用ORSSD、EORSSD和ORSI-4199任务标注、且不针对这三个数据集更新模型参数的条件下，本文的“冻结MLLM + PRISM + 冻结SAM2”是否优于可复现的同类方法？**

弱标注、跨数据集监督和全监督方法用于说明不同监督成本下的性能位置，必须单独分组，不能与核心无任务训练结果混排，也不能据此宣称本文在全监督精度上领先。

## 3. 监督条件分组

| 组别 | 定义 | 是否进入核心主表 | 典型情况 |
|---|---|---|---|
| T0 无任务训练 | 不使用目标三集的任何训练标注；不以目标三集图像或标注更新参数；允许使用公开冻结基础模型 | **是** | SR、FT、冻结MLLM/通用分割器、本文PRISM |
| T1 目标域零标注 | 不使用目标三集标注，但可能用目标域无标注图像训练、适配或统计 | 否，单独分组 | 自训练、测试时适配、目标域无监督训练 |
| T2 跨数据集任务监督 | 不使用目标三集标注，但曾用其他SOD数据集的像素级或弱标注训练 | 否，单独分组 | 在自然图像SOD上训练后直接迁移 |
| T3 目标域弱标注 | 使用目标三集训练划分的图像级标签、点、涂鸦、框或伪标签人工种子 | 否，单独弱标注表 | 图像级、点级、框级、涂鸦监督SOD |
| T4 目标域全监督 | 使用目标三集训练划分的像素掩码 | 否，仅作辅助参照 | GeleNet、本文监督校准器 |

补充判定规则：

1. “没有使用测试集标注”不足以归入T0；只要使用目标数据集训练标注，就归入T3或T4。
2. 使用其他SOD数据集的任务标注训练，归入T2，不能称为与本文同等的无任务训练。
3. 使用目标测试图像进行无标签参数更新、聚类或统计，归入T1，并注明是归纳式还是传导式设置。
4. ImageNet、通用视觉语言数据、SAM/SAM2分割数据等基础预训练可以保留，但必须披露模型、权重和预训练性质。
5. MLLM在线调用与离线缓存提示在监督等级上等价；必须记录模型版本、提示模板及缓存是否在方法冻结前产生。
6. 论文中的GT框、GT提示统计和Oracle结果不属于可比较方法，只能出现在诊断或上界分析中。

## 4. 固定输入、输出与后处理

1. 每种方法都接收同一批原始测试图像。允许使用该方法官方仓库规定的尺寸变换，但必须记录输入尺寸和恢复方式。
2. 最终预测保存为单通道8位PNG，目录结构为 `方法名/数据集/maps/`，文件名必须与GT的PNG文件名一致。
3. 优先在方法内部将显著图恢复到原图尺寸。若尺寸仍不一致，统一评测器按 `ds_sod/eval/metrics.py` 当前实现调整到GT尺寸。
4. 保留方法原始的连续显著性值。不得为了提高测试成绩，使用测试GT搜索二值化阈值、连通域阈值、CRF参数或其他后处理参数。
5. 仅允许使用官方默认后处理或在查看测试GT前固定的统一后处理；必须在结果表中披露。
6. 每个方法均要检查缺图、同名覆盖、空白图、全常数图和异常尺寸。任何一个数据集预测数不足时，不得写入正式结果表。

## 5. 固定指标实现

唯一正式评测入口为：

```text
ds_sod/scripts/eval_mllm.py
```

底层实现为 `ds_sod/eval/metrics.py`，当前规则如下：

- GT以灰度值大于128二值化。
- 预测图读取为灰度图并缩放到 `[0,1]`；非常数图逐图做最小—最大归一化。
- S-measure使用 `alpha=0.5`。
- F-measure使用社区常用的 `β²=0.3` 口径，并在256个阈值上计算；保存 `Fβmax` 与 `Fβmean`。
- E-measure在256个阈值上计算；保存 `Eξmax` 与 `Eξmean`。
- MAE在连续显著图与二值GT之间计算。
- 各数据集指标先对该数据集所有图像逐图等权平均。

论文主表至少报告 **Sα和MAE**；完整补充表报告 **Sα、Fβmax、Eξmax和MAE**。数值使用完整精度计算，表格统一保留四位小数。

三集综合值按数据集等权平均：

```text
Macro = (ORSSD + EORSSD + ORSI-4199) / 3
```

不得按2,999张图加权，因为这会使ORSI-4199主导综合结果。Sα、Fβmax、Eξmax越高越好，MAE越低越好。

## 6. 完整性与可复现性门槛

一个方法进入本地复评表前必须同时满足：

1. ORSSD、EORSSD、ORSI-4199分别得到200、600、2,199张有效预测。
2. 三个数据集全部通过统一评测脚本的完整性守卫。
3. 保存论文、代码仓库、代码版本或commit、权重来源、配置文件、执行命令、输入尺寸和后处理说明。
4. 不使用测试GT调参，并在实验记录中明确确认。
5. 官方确定性预训练权重可完整运行一次；若训练或推理具有明显随机性，应优先报告官方多种子协议。算力不足只能运行单种子时，必须标注为单次复评，不能报告不存在的方差。
6. 运行失败或只覆盖部分数据集的方法保留在可复现性记录中，但不计算三集宏平均。
