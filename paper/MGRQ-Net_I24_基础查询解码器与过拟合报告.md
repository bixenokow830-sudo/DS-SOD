# MGRQ-Net I24｜基础查询解码器与过拟合报告

## 1. 执行结论

I24 已完成并通过验收（`PASSED`）。已建立不含可靠性头和两阶段细化的最小查询掩码解码器，并在严格训练清单中的12张图上完成真实冻结SAM2特征过拟合。

训练损失由1.6857下降至0.0398，下降97.64%；训练图平均显著掩码并集IoU达到0.9519，平均匹配组件IoU达到0.8891，证明I20–I24的数据目标、文本缓存、候选查询、匈牙利匹配和掩码解码链路能够联合学习。

该结果仅证明基础设施可训练和可恢复训练掩码，不代表开发集或测试集泛化性能。

## 2. 冻结结构

| 项目 | 设置 |
|---|---|
| 查询维度 | 256 |
| 解码器 | 3层Transformer Decoder |
| 注意力头 | 8 |
| FFN维度 | 1024 |
| MLLM查询上限 | 5 |
| 可学习发现查询 | 5 |
| 掩码阶段 | 单阶段 |
| 输出分辨率 | SAM2特征分辨率 |
| dropout | 0 |

解码器把最多5个I22候选查询与5个可学习发现查询拼接。查询经过三层交叉注意力读取冻结SAM2空间特征，再通过查询掩码嵌入与像素投影的点积生成每个查询的组件mask logits。

二维正弦位置编码加入SAM2空间特征。空MLLM候选时仍保留5个发现查询；批内无效MLLM槽被注意力掩蔽，其mask logits固定为-20。

## 3. 损失与匹配

- 匹配：复用I23组件级匈牙利匹配器；
- 已匹配查询：`BCEWithLogits + soft Dice`；
- 未匹配查询：`0.1 ×`空背景BCE；
- 匹配框：由当前mask logits在0.5阈值下转换为归一化外接框，仅用于离散匹配；
- 没有引入语义匹配代价、可靠性头或两阶段细化。

SAM2图像编码器和I21 CLIP文本特征保持冻结。过拟合实验仅优化I22候选查询构造器、发现查询、3层解码器、像素投影和掩码嵌入，共4,433,024个参数。

## 4. 过拟合数据协议

从D14严格train中确定性选择12张图，每个数据集4张：

- EORSSD：`0019`、`0035`、`0040`、`0041`；
- ORSI4199：`10`、`100`、`1000`、`1001`；
- ORSSD：`0002`、`0028`、`0029`、`0031`。

全部记录的`split=train`且`official_split=train`，没有使用dev或官方test图像。候选框来自D14冻结提示，文本向量来自I21缓存，组件监督来自I20目标库。

使用SAM2.1 Base+真实图像编码器提取冻结特征，并下采样至32×32用于快速基础设施过拟合。该操作不更新SAM2权重，也不复用M04已经训练的SAM2 mask decoder。
