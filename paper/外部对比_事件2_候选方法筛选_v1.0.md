# 外部零标注与弱标注对比：事件2候选方法筛选 v1.0

状态：**候选筛选完成，待作者审核**  
调研日期：2026-10-10  
依据协议：`外部对比_事件1_评测协议_v1.0.md`

## 1. 筛选目标

本事件只筛选值得进入下一步可复现性审计的方法，不下载代码、不安装依赖、不运行实验。筛选优先级依次为：

1. 与本文同属单幅图像SOD，且不使用任务标注、不进行任务训练；
2. 能在ORSSD、EORSSD或ORSI-4199上产生像素级显著图；
3. 有公开论文、代码、权重或预测图；
4. 能通过本仓库统一评测器重新计算指标；
5. 能代表训练自由、无人工标注训练和弱标注三种不同监督成本。

## 2. 调研中发现的协议分类缺口

事件1的T0–T4分类还缺少一种常见情况：方法**不使用任何人工标注，但会在其他数据集上训练任务专用的SOD网络**。3SD和A2S-v3均属于这一类。

建议在正式锁定协议时新增：

| 建议组别 | 定义 | 与T0的区别 |
|---|---|---|
| T2-U 外部无标注任务训练 | 不使用目标三集标注，但在其他无标注图像上以伪标签、自监督或知识蒸馏方式训练SOD模型 | 使用了任务专用训练，不能进入T0核心表 |

如果A2S-v3进一步使用ORSSD、EORSSD或ORSI训练图像进行无标注适配，则仍应归入T1“目标域零标注适配”；只有使用外部无标注数据训练后直接迁移的版本归入T2-U。

## 3. 建议保留的五个候选方法

### 候选1：FOCUS（最高优先级）

- 论文：*Is It Time for the Renaissance of Salient Object Detection in the Era of MLLMs?*，2026。
- 预分类：**T0无任务训练**。
- 方法性质：冻结MLLM、自监督视觉特征和通用分割器，通过前景数量、粒度和范围组织生成显著掩码。
- 入选理由：这是与本文问题最接近的外部方法；同样研究MLLM定位证据、提示组织和训练自由SOD，可以直接回应导师提出的“与零标注方法比较”。
- 已知资源：论文声明代码包含在补充材料中；尚未确认补充代码是否完整、模型/API要求以及能否直接处理遥感数据。
- 数据差异：原论文报告13个RGB、RGB-D和RGB-T基准，没有报告ORSSD、EORSSD和ORSI-4199，必须本地复评，不能引用原论文数字直接比较。
- 目标证据等级：A；如果代码不完整则降为D，只在相关工作讨论。
- 主要来源：<https://arxiv.org/abs/2607.29222>

**事件3重点核查：** 补充材料中的代码入口、MLLM型号、通用分割器、DINO版本、数据组织方式、API成本和是否需要人工编写每个数据集的观察协议。

### 候选2：A2S-v3（最高优先级的无人工标注训练参照）

- 论文：*Unified Unsupervised Salient Object Detection via Knowledge Transfer*，IJCAI 2024。
- 预分类：直接零样本迁移版本为**T2-U**；使用遥感训练图像无标注适配的版本为**T1**。
- 方法性质：从预训练网络蒸馏显著性线索，使用伪标签训练显著性检测器，并支持从自然图像SOD向遥感SOD迁移。
- 入选理由：论文明确研究遥感SOD迁移；官方仓库列出ORSSD、EORSSD和ORS数据，并提供RSI预计算显著图链接。它是当前最贴近本文数据集的“无人工标注但有任务训练”代表。
- 已知资源：公开代码、训练与测试命令、自然图像预训练权重、遥感适配权重和RSI显著图；部分资源位于百度网盘。
- 限制：必须区分论文的零样本迁移版本与遥感无标注微调版本，二者不能混成一个结果。
- 目标证据等级：优先B（官方显著图统一复评），条件允许再达到A。
- 论文：<https://arxiv.org/abs/2404.14759>
- 代码：<https://github.com/I2-Multimedia-Lab/A2S-v3>

**事件3重点核查：** 仓库中的`ORS`究竟是否为本文的ORSI-4199、官方显著图对应哪种训练设置、三个测试集文件主名是否与本地划分一致。

### 候选3：3SD（通用无人工标注训练参照）

- 论文：*3SD: Self-Supervised Saliency Detection With No Labels*，WACV 2024。
- 预分类：**T2-U外部无标注任务训练**。
- 方法性质：利用自监督分类分支产生CAM，并与边缘信息组合成伪GT，再训练SOD网络。
- 入选理由：论文明确强调不使用像素、涂鸦等人工标签；有正式会议论文与公开代码，适合作为“零人工标注不等于训练自由”的代表。
- 已知资源：公开代码；论文在自然图像SOD数据集上评测，没有遥感三集结果。
- 限制：仍然训练任务专用SOD网络，因此不能进入T0核心表；遥感域迁移效果未知。
- 目标证据等级：A或C，取决于预训练权重是否公开且能直接对遥感图像推理。
- 论文：<https://openaccess.thecvf.com/content/WACV2024/html/Yasarla_3SD_Self-Supervised_Saliency_Detection_With_No_Labels_WACV_2024_paper.html>
- 代码：<https://github.com/rajeevyasarla/3SD>

**事件3重点核查：** 是否提供可下载的最终权重、是否必须重新训练、测试脚本能否接受任意图像目录、依赖版本和显存需求。

### 候选4：LightEMNet（现代遥感弱标注参照）

- 论文：*Lightweight Edge-Aware Mamba-Fusion Network for Weakly Supervised Salient Object Detection in Optical Remote Sensing Images*，IEEE TGRS 2025，DOI `10.1109/TGRS.2025.3587287`。
- 预分类：**T3目标域弱标注**，监督形式为涂鸦。
- 方法性质：MobileNetV2骨干、边缘感知与Mamba跨尺度交互。
- 入选理由：专门面向ORSI-SOD，年份较新，能够代表当前遥感弱监督路线；官方仓库提供测试结果图和训练模型下载入口。
- 已知资源：公开代码、测试结果图、训练模型；下载链接为百度网盘。
- 限制：仓库说明较简略，尚未确认三个数据集是否全部提供以及涂鸦训练集如何构造。
- 目标证据等级：优先B，若结果图覆盖不完整则尝试A。
- 代码与结果：<https://github.com/xingggao/LightEMNet>

**事件3重点核查：** 结果图覆盖ORSSD/EORSSD/ORSI-4199的情况、权重和配置对应关系、训练标注来源、许可证和Python/PyTorch版本。

### 候选5：SBA-Net（可复现的遥感涂鸦弱标注锚点）

- 论文：*Scribble-based Boundary-aware Network for Weakly Supervised Salient Object Detection in Remote Sensing Images*，ISPRS Journal of Photogrammetry and Remote Sensing，2022。
- 预分类：**T3目标域弱标注**。
- 方法性质：基于S-EOR涂鸦标注训练边界感知遥感显著性网络。
- 入选理由：这是较早但定义清晰的遥感涂鸦SOD基线；官方仓库同时提供代码、数据和测试结果入口，适合成为弱标注表的稳定锚点。
- 已知资源：公开代码、S-EOR数据、测试结果和MATLAB评测入口。
- 限制：主要围绕ORSSD/EORSSD，预计不能形成完整的ORSI-4199结果；如缺少第三集，只报告逐集结果，不计算三集宏平均。
- 目标证据等级：B或A。
- 论文：<https://arxiv.org/abs/2202.03501>
- 代码：<https://github.com/ZhouHuang23/SBA-Net>

**事件3重点核查：** 官方测试图对应的数据划分、是否含ORSSD与EORSSD完整预测、权重是否仍可下载、旧环境兼容性。

## 4. 暂不进入首轮复现的相关方法

| 方法 | 暂缓原因 | 后续用途 |
|---|---|---|
| ScribbleSAM（2025） | 遥感弱标注且与SAM相关，概念上很适合；本轮尚未找到明确的官方代码仓库或完整预测图入口 | 先作为文献参照；若事件3找到代码，再替换SBA-Net或加入弱标注表 |
| MNEFNet（2026） | 论文在线信息较新，暂未确认官方代码、权重和显著图 | 相关工作引用，等待资源公开 |
| TF-SSD（CVPR 2026） | 严格训练自由，但任务是CoSOD，需要预定义图像组；直接用于单图ORSI-SOD会改变任务定义 | 不进入正式主表，可作为方法设计相关工作 |
| Zero-Shot CoSOD Framework（2024） | 同样依赖协同显著图像组，与本文单图测试协议不一致 | 不复现 |
| Saliency-R1（CVPR 2026） | 通过SFT/GRPO训练MLLM，主要评测视觉语言推理与注意力对齐，不直接提供标准ORSI-SOD显著图 | 相关工作引用，不作为同协议分割基线 |
| Parameter-Free SOD Network（2026） | 推理模块本身无参数，但建立在已经训练过的SOD模型上，监督成本取决于底座；当前未确认公开代码 | 暂缓，必要时归入T2而非T0 |

## 5. 首轮优先顺序

事件3建议按以下顺序做可复现性审计：

1. **FOCUS**：决定核心T0对比能否成立。
2. **A2S-v3**：最可能直接取得遥感官方显著图，且包含零样本迁移与遥感适配两种设置。
3. **LightEMNet**：最可能用官方结果图快速形成现代遥感弱标注参照。
4. **SBA-Net**：补充稳定的遥感弱标注基线。
5. **3SD**：用于通用无人工标注任务训练参照；若没有权重或必须长时间重训，可以降为文献参照。

## 6. 事件2结论

建议保留五个首轮候选：**FOCUS、A2S-v3、3SD、LightEMNet、SBA-Net**。

它们承担的证据角色不同：

- FOCUS回答“与真正训练自由的MLLM/SOD方法相比如何”；
- A2S-v3与3SD回答“与无人工标注但进行SOD任务训练的方法相比如何”；
- LightEMNet与SBA-Net回答“与使用涂鸦弱标注的遥感方法相比如何”。

当前还不能承诺五种方法都能完成三集A/B级复评。资源有效性、划分一致性、权重设置和运行成本将在事件3逐项核实。本事件没有下载、安装或执行任何候选方法。
