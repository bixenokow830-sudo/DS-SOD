# DS-SOD「框纠正与利用」改造方案：详细修改步骤

> 依据：导师指导意见（角色区分 + 创新收缩到具体环节）+ 已确认的三个修改点
> ① 方向 = 框纠正与利用 ｜ ② 主模块 = 框校准器（带分割反馈），多候选/自校验为消融变体 ｜ ③ 纳入可替换性实验
> 状态：**待审核，未执行** ｜ 本方案不改动论文，审核通过后按步骤号执行

---

## 0. 改造总览

```
旧叙事：MLLM(语义框) → 冻结 SAM2 → [掩码适配器]  → 贡献分散在三处
新叙事：MLLM(意图) → 框校准器(主贡献) → 冻结 SAM2(执行) → [解码校准(adapter)]
         └── 校准层：先校框、后校掩码，创新聚焦"校准"这一个环节
```

复用资产：`mask_bank.json`（粗框来源，$5.59 已付）、训练集 GT（4000 张）、SAM2 冻结
编码器特征、评测管线（eval_mllm.py）、SelfCheck 机制（变体C用）。

---

## 1. 数据准备（D1）

- **D1-1 GT 框提取**：复用 `abl_boxes.py` 的连通域逻辑，从三数据集训练集 GT 掩码提取
  逐实例 GT 框（4000 张，约 8000+ 框）。
- **D1-2 MLLM 框误差标定**：在 dev 50 上统计 MLLM 框 vs GT 框的误差分布（中心偏移、
  宽高比偏差、IoU 分布）——**校准器要学的是"这个分布的逆映射"**，先量化它。
- **D1-3 粗框仿真器**：GT 框 + 按误差分布采样抖动（平移/缩放/长宽扰动），生成训练输入
  "粗框"，使训练分布与推理时的 MLLM 框误差同源。

## 2. 框校准器设计（M1）

- **M1-1 图像特征**：冻结 SAM2 image encoder 的 `image_embed`（256×64×64，`set_image`
  已有缓存），对粗框区域 ROI 池化 + 全图均值池化——**零额外骨干、零额外成本**。
- **M1-2 分割反馈特征**（本文设计核心）：粗框经 SAM2 首轮解码后，提取一致性向量：
  掩码质心与框中心的偏移、掩码/框面积比、四边各自的不一致量（掩码边缘超框/欠框距离）、
  首轮候选质量分。动机直接来自失败分析——"框与掩码不一致"正是桥/操场/成簇目标失败的主因。
- **M1-3 回归头**：MLP（[ROI特征, 全图特征, 粗框编码, 反馈向量]）→ 四边残差 Δbox
  （归一化到框尺寸），输出 校正框 = 粗框 + Δbox。
- **M1-4 参数量目标**：<1M（保持"轻量校准"叙事）。

## 3. 训练协议（T1）

- **T1-1 损失**：L = GIoU(校正框, GT框)。（掩码级损失因 SAM2 冻结不可微，不设；
  GIoU 是标准可靠的框回归监督。）
- **T1-2 数据**：D1-3 仿真粗框（每图按实例数 1～5 框；负样本=无目标图跳过）。
- **T1-3 超参**：AdamW lr=1e-4，5～10 epoch（轻量头收敛快）；每图仅需一次冻结编码器
  前向 + 每框一次首轮解码，8GB 显存充裕。
- **T1-4 预估训练时长**：约 1 小时（本地 GPU，$0）。

## 4. 推理协议（I1）

- 粗框 → SAM2 首轮解码（**只为取反馈**）→ 校准器 → 校正框 → SAM2 二轮解码 → 最终掩码；
- 速度代价：每实例 +1 轮解码（实测 0.126s/框），可接受；
- none 图（无粗框）直接全零输出。

## 5. 消融变体（A1～A3）

- **A1 核心消融**（论文新表2）：
  ① 无任何校准（= hybrid-b 基线）→ ② 仅框校准 → ③ 仅掩码校准（现有 adapter）→
  ④ 框+掩码校准（完整 DS-SOD）。**回答"哪个校准环节最值钱"**。
- **A2 变体 B（多候选打分）**：粗框 + 缩放变体（0.8/1.0/1.2）生成多候选 → 校准器加
  打分头选优。与回归版对比"选 vs 修"。
- **A3 变体 C（自校验触发）**：校准后一致性分数仍低的实例，触发一次 SelfCheck 修框
  （复用现成 `selfcheck_full.py` 机制，仅对低置信实例调用，控制 API 成本）。

## 6. 可替换性实验（R1）

- **R1-1 弱提示源构造**：① 随机框（已有 abl-random-box）；② 中心框（图像中心固定比例）；
  ③ MLLM 中心点 + 固定尺寸框（**去掉 MLLM 的尺寸/形状信息，只留"什么显著+在哪"的
  语义意图**）。
- **R1-2 每组报告**：无校准 Sα vs 有校准 Sα。
- **R1-3 论证与验收**：若"弱源 + 校准"能逼近"MLLM 框 + 校准"（差距 ≤3pt），则证明
  **贡献在"校"不在"源"**——直接回应导师"先验过强"的担忧；MLLM 从"精度来源"降格为
  "可替换的意图来源"。

## 7. 验证与验收（V1）

- **V1-1 dev 50 先行**：报告框 IoU 提升（MLLM框→校正框 vs GT）与掩码 Sα 提升
  （基线 hybrid-adapter3ds dev=0.887）。
- **V1-2 验收门**：全量测试集 Sα 相对现基线（0.8648/0.8528/0.7990）**提升 ≥2pt**，
  且 A1 消融中"仅框校准"增益 ≥"仅掩码校准"增益（证明主贡献成立）。
- **V1-3 不足 +2pt 时**：按序调 ① 迭代 2 次校准；② 反馈特征扩充（加边界点特征）；
  ③ 抖动分布调参；一轮后仍不足 → 如实报告并收缩叙事（"框校准为辅助组件"）。

## 8. 论文改写（P1～P6，按章节）

- **P1 摘要/引言**：改为"意图-执行-校准"三段式；贡献收缩为 **1 主（带分割反馈的框校准器）
  + 2 辅（角色分工范式、低成本可复现资产）**。
- **P2 方法**：新增 3.4"框校准器"（含 GIoU 公式、Δbox 表示、反馈向量定义、图2 模块图）；
  原 4.22M adapter 降级为 3.5"解码校准"，定位从"核心训练组件"改为"校准层第二级"。
- **P3 实验主表**：方法行改为"DS-SOD（框校准+解码校准）"，并加"仅框校准"行。
- **P4 消融重排**：新表2 = 校准消融（A1）；原提示来源表降级为辅助（配合 R1 可替换性表，
  论证"意图必要但可替换"）。
- **P5 相关工作总结句**：SAM2-RS "学提示" vs 本文 "校提示"。
- **P6 图1 框架图**：更新为"意图-执行-校准"（框校准器与反馈回路入图）。

## 10. 决策点（已确认，2026-09）

1. **D-1 adapter 定位**：✅ **保留主线**——"两级校准"统一叙事（框校准 = 主贡献；解码校准 = 校准层第二级），A1 四格消融拆解两者。
2. **D-2 校准迭代次数**：✅ **2 次**（首轮反馈 → 校正 → 二轮反馈 → 残差再校正）。
3. **D-3 弱提示源集合**：✅ **随机框 / 中心框 / MLLM中心点+固定框** 三个。
4. **D-4 验收门**：✅ 认可 **全量 Sα ≥ +2pt**（相对现基线 0.8648/0.8528/0.7990）作为"框校准为主贡献"的门槛。

## 11. V1-1 实验结论与主贡献定稿（2026-09 实测）

**框校准实验（两轮迭代：GIoU 符号修复 + 训练/推理适配器对齐）结论（dev 50）**：

| 变体 | Sα | IoU | 相对"无校准" |
|------|-----|-----|-------------|
| ① 无校准（raw+box） | 0.7944 | 0.6002 | 基线 |
| ② 仅框校准 | 0.8044 | 0.6087 | +1.0pt |
| ③ 仅解码校准（adapter 4.22M） | 0.8865 | 0.7530 | **+9.2pt** |
| ④ 框+解码校准 | 0.8859 | 0.7399 | +9.2pt（与③重叠） |

- 框校准器框级有效（框 IoU +5.3pt，46 变好/20 变差），但掩码级增益小且与解码校准重叠；
- 根因：适配器训练时的"框抖动鲁棒性"已隐式吸收框误差；
- **数据支持导师方向 (a)：主贡献 = 解码校准（掩码纠正校准）；框校准 = 诚实消融（+1pt、与解码校准重叠）**。

**✅ 已确认（导师/用户）：主贡献从"框校准"调回"解码校准（掩码纠正校准）"**。
论文叙事：意图-执行-校准；校准层 = 解码校准为主（+9.2pt）、框校准为辅（+1pt 消融）。

**R1 可替换性实验（已完成，三数据集平均 Sα）**：

| 提示源 | 无校准 | +解码校准 | 增益 |
|--------|--------|----------|------|
| 随机框 | 0.465 | 0.667 | +20.3 |
| 中心框 | 0.547 | 0.731 | +18.4 |
| MLLM中心点+固定框 | 0.582 | 0.769 | +18.7 |
| MLLM 框 | 0.762 | 0.839 | +7.7 |

结论：校准增益与提示源质量成反比；"弱源+校准"≈"强源+无校准"——贡献在"校"不在"源"，
MLLM 为可替换的意图来源（正面回应"先验过强"）。
