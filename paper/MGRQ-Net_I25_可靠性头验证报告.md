# MGRQ-Net I25｜查询可靠性头验证报告

## 1. 执行结论

I25 已完成并通过验收（`PASSED`）。在 I24 的 256 维解码查询后新增双分支可靠性头，分别预测目标存在概率 `p_obj` 与掩码质量 `p_iou`，最终查询可靠性定义为：

```text
r_i = p_obj × p_iou
```

在固定种子 42 的独立人工留出集上，正查询平均可靠性为 0.819689，负查询为 0.00000461，二者差值为 0.819684；目标分类准确率为 100%，可靠性标准差为 0.344802，未出现全 0 或全 1 塌缩。

该阶段只验证可靠性头的结构、监督逻辑和可优化性。人工数据结果不能替代真实开发集上的可靠性校准与泛化评估。

## 2. 结构设计

| 项目 | 设置 |
|---|---|
| 输入 | I24 解码后的 256 维查询 |
| 共享投影 | LayerNorm → Linear(256,128) → GELU |
| 目标分支 | Linear(128,1) → Sigmoid，输出 `p_obj` |
| 质量分支 | Linear(128,1) → Sigmoid，输出 `p_iou` |
| 最终可靠性 | `p_obj × p_iou` |
| 可训练参数 | 33,666 |
| 无效 padding 查询 | 三项输出均严格置零 |

双分支设计将“是否对应真实显著目标”和“预测掩码质量是否足够高”拆开建模，避免仅凭目标存在置信度保留边界质量很差的查询。

## 3. 监督定义

I25 复用 I23 的一对一组件级匹配结果：

- 已匹配查询的目标存在标签为 1；
- 未匹配查询、背景查询和重复查询的目标存在标签为 0；
- `p_iou` 的软目标为匹配查询当前二值掩码与对应 GT 组件的实际 IoU；
- 未匹配查询的 IoU 目标为 0；
- 无效 padding 查询不参与损失。

目标存在分支采用二元 Focal Loss，正类权重 `alpha=0.75`、聚焦参数 `gamma=2.0`，用于缓解查询中负样本较多的不平衡。质量分支采用 Smooth L1 回归损失，总损失为：

```text
L_reliability = L_focal(p_obj, y_obj) + L_smoothL1(p_iou, y_iou)
```
