## 1 三条意见的逐条诊断

### 1.1 意见①：不得以低成本为卖点

| 位置 | 现有表述 | 问题 |

| §1.3 贡献 2 | "仅 4.22M 参数……相对冻结基线 +11.0 点" | 同上 |
| §4.2 分析 4 | "成本-精度位置……这一 Pareto 位置是本文相对全监督方法的核心论据" | **最严重：把 Pareto 效率当核心论据** |
| §4.8 效率与成本 | 整节（显存三口径、API $5.59/$3.66、推理速度） | 整节以成本为叙事 |
| §5 讨论 | "PRISM……是本框架中性价比最高的一步" | "性价比"措辞 |

同时要纠正一个**隐含的失实风险**：MLLM 与 SAM2 本身并不便宜（视觉大模型 API + 224M 级主干推理），
"我们便宜"这一命题本身站不住。**处理办法**：**一切金额数字（$5.59 / $3.66）从论文中全部删除**
（导师已确认，见 §0.1 与 §6），只保留"可训练参数量 / 训练时长 / 硬件"这类复现信息并移入附录；
全文不再出现"低成本/性价比/Pareto/仅需/n 倍少"等作为论据的表述。
**"零标注"是标注语义概念，与钱无关，必须与成本彻底解耦。**

### 1.2 意见②：以"零标注 + 开放世界"切入，创新点越小越具体越好

初稿的定位（v0.7 页眉）是"**机制与能力边界研究，不参与 SOTA 精度竞争**"——这是"论文不做什么"的
定位，不是创新点。它导致三处结构性毛病：

1. **没有明确的问题边界**：§4.5"范式上限"、§4.9"与全监督失败模式互补"、T2/T4"补漏证伪"、
   主干扩展零增益等**负面结论**在全文权重过大（约占 §4.5/§5/§6 的一半）；
2. **同级基线还不完整**：主表同级只有 SR/FT（经典无监督）、随机/中心/固定点（无语义先验）与
   自建 Hybrid，**没有任何弱标注基线**（SBA-Net 一行已因数值无法核实而被删除，见
   `DS-SOD_数据溯源与真实性声明.md` 第 72、207 行；初稿末尾"待办①"也承认缺同级外部基线）。
   → 本文最终决定**不补这一对照**，改为用内部 oracle 承担对照职责，并在结论中明确划界
   （§3.5 末、§7），完整设计留作 revision 保险（§4 P0-a）；
3. **卖点缺位**：与 SAM2-RS（冻结 SAM2 + 盲提示向量）、SR/FT、FOCUS 的差异，目前只写在 §2.2 一段，
   未上升为创新点。

**结论**：需要一个"小到可被验证"的创新点。切入词已定为**"零标注"**（导师确认）；
"开放世界"降级为 L5 边界章节（§3.4）。

### 1.3 意见③：比较对象换成零标注与弱标注 → **本文最终只比较零标注（导师 2026-10 追加决定）**

意见③的原意是"只需超过完全零标注与弱标注，不必超过全监督"。本文执行时收窄为：
**零标注同级比较 + 内部 oracle 标尺**；**弱标注对照明确不做**（理由与 revision 预案见 §7）。
因此 L4 的落点从"vs 弱标注"改为"人工提示的边际价值 2.1 点 / 范式代价 0.7 点"（§3.5）。

初稿把大量篇幅用于回答"与全监督差几点、差在哪"（§4.9、§5"为什么仍落后 5～7 点"）。
按意见③，**这些问题应当降级为边界讨论**，主力篇幅改为：在同一测试划分、同一指标实现下，
把方法放到"监督级别阶梯"上定位。

## 2 重新定位（核心）

### 2.1 一句话切入点

> **在"目标域零像素标注 + 目标类别不在训练预设闭集内"的设定下，把大模型给出的自然语言提示
> （粗框）当作"不可靠证据"来建模与修复：即使 53% 的提示框打偏或选错目标，仍能输出可用的像素显著图。**

### 2.2 具体问题（越小越具体）

**问题**：MLLM 的提示框在遥感域失效率极高——
- 仅 **47.2%** 严格命中显著目标（IoU≥0.5），**32.1%** 完全选错目标（IoU<0.1）；
- 框并集像素**召回 82.0%**、**精确仅 38.4%**（"没漏，但盖得太多太散"）；
- 误差集中在**主体之外的多余实例**：框类别与真值一致时严格匹配率 **67.7%**，不一致时仅 **9.4%**，
  而最高置信框的类别正确率高达 **91.3%**（模型"认得出主体是什么"，但会多吐实例）；
- 全测试集 6266 框中 **53%（3308 个）是打偏/选错框**，中心偏移均值达 **-1.52 个目标边长**。

**要解决的具体子问题**（只此一个，不再扩张）：
> **这种"结构性不可靠"的提示，能否在"零训练纠错 + 训练期分布内化"两个层面被修正？**

### 2.3 两条互补技术线（把现有工作重新组织，不需要新机制）

| 层面 | 名称 | 内容 | 已有实测增益 |
|---|---|---|---|
| 推理侧（零训练、免 GT） | **PRISM 提示修复** | 类别一致性过滤 + 掩码自收紧 + 超大框守卫 | 旧校准器单独 **+2.76**；新校准器边际 **+0.92** |
| 训练侧（只用训练集 GT，不接触目标域标注） | **提示分布对齐** | 抖动 10%→30%（+3.30）；负样本提示拒绝（+0.92）；真实错框分布重采样（+1.49，两种子平均） | 合计 **+5.14～+6.6** |

关键实证结论（保留为方法学发现）：
- **"筛选必须克制"**：激进拒绝（τ=0.9）使 Sα 崩塌 **6.2 点**，Sα 对漏检远不如对误检敏感
  → 提示筛选只能以下游指标为目标，不能以"框分类准确率"为目标；
- **"训练内化 vs 推理修复"**：新协议下 FP/EXT 两类 oracle 已与本文持平（0.8802/0.8826 vs 0.8811）
  → 部分筛选工作被解码器在训练阶段内化，二者存在部分冗余（**如实报告**）。

### 2.4 "开放世界"必须落到两个可测判据

| 判据 | 含义 | 现状 |
|---|---|---|
| **未见数据集零样本迁移** | 在 A/B 上适配，直接在**从未见过的** C 上评测（无目标域训练、无目标域标注） | **完全未做**（现有 T3 校准器在三集全量训练集上训过） |
| **未见类别泛化（开放词表）** | 显著类别不在训练类别集合内，仅靠语言提示定义"什么显著" | **完全未做**（ORSI-4199 文件名自带 9 类标签，可做） |

现有"语义先验"证据（固定点框 0.780 vs MLLM 框 0.881，**三集平均 +10.1 点**；
校准增益与提示源无关，弱源上 +18～21 点）**升级为"开放世界的必要性与可行性"的支撑证据**，
而不再只是"可替换性"消融。

### 2.5 与 SAM2-RS 的差异必须重写（**本轮核查有重大发现**）

| 对比对象 | 提示来源 | 目标域标注 | 训练 | 类别 |

### 2.7 "零标注"的定义与诚实边界（**投稿红线，必须一次性写清**）

| 阶段 | 标注使用情况 | 说明 |
|---|---|---|

## 3 分级实验框架（**以"零标注"为唯一切入点**，导师已确认）

### 3.1 设计原则：每一格只允许改变一个变量

全部分级实验只围绕一个问题展开：**在目标域零像素标注的条件下，"不新增人工标注"能把遥感显著
检测做到什么程度、代价落在哪、边界在哪里。** 因此每个变体只允许相对相邻变体改动**一个**因素
（有无训练 / 提示有无语义 / 监督信号强度 / 域或类别），使**相邻两格的差值本身成为一条可独立
主张的结论**，而不是把一堆改动打包成一个总分。

### 3.2 监督级别阶梯（x = 标注强度，y = Sα；**本文主张：零标注曲线逼近 A4 oracle，人工提示边际价值仅 2.1 点**）

```
Sα
0.93 ┤                                    D 全监督 GeleNet 0.9235（同协议复评）
0.92 ┤  ◆ A4 GT 框 + 同校准器 0.9168 ────  ← 理想人工提示的 oracle 上界
0.90 ┤  ★★★ B2 本文主结果 0.8961 ────────┤  ← 本文落点：不新增任何标注
0.88 ┤                                    │
0.84 ┤                                    │
0.78 ┤  A3 固定点框 0.780（无语义上界）    │
0.78 ┤  ★ A2+P 冻结 SAM2 + PRISM 0.7845 ◄─┘  ← 零训练·零参数（实测）
0.76 ┤  A2 冻结 SAM2 执行 0.7618           │
0.73 ┤  A1 中心框 0.727｜随机框 0.673      │
0.67 ┤  A0 纯几何 0.6660                   │
0.54 ┤  T2 经典无监督 FT 0.539｜SR 0.501   │
     └──────────────────────────────────────────────────────────────►
        零标注·零训练     零标注·需训练           全监督
```

**这张图就是论文的立意**：在横轴最左端（零标注）把曲线顶到接近 A4 oracle 的位置，
**使"人工提示的边际价值"降到 2.1 点**，是全文唯一要证明的事。

> **关于弱标注**：本方案**不设弱标注对照**（导师已定）。替代物是上图中已有的三行内部对照——
> `B2 0.8961 → A4 0.9168（理想人工提示）→ D 0.9235（全监督）`。它们同架构、同数据、同预算，
> 因此"人工提示值多少点"这个问题仍然有答案，只是衡量的是**提示级人工**而非框/涂鸦级人工。
> 设计完整的弱标注三级阶梯已整章降级为**可选补充实验**（见 §4 P0-a）。

#### A. 这个实验要回答什么

**一个单变量问题**：在同一基干网络、同一训练数据、同一训练预算下，把**监督信号**从
"MLLM 提示 + 公开集掩码"换成"人工框 / 人工涂鸦"，性能会怎么变？

**它的用途是 revision 保险，不是论证支点**。若补做，结论按结果如实写：

- 若弱标注**低于或等于** B2（0.8961）→ 可写 "zero-annotation reaches (or surpasses) weak supervision"；
- 若弱标注**高于** B2 → 只能写 "zero-annotation reaches the level of weak supervision"，
  价值落在"省掉人工标注"，**不得声称效果更好**。

> 主实验已由 §3.5 的内部 oracle 承担（A4 − B2 = 2.1 点、D − A4 = 0.7 点），
> 因此**无论本节是否补做，论文的核心主张都不受影响**——这正是把它降级为可选的前提。

#### B. 预先声明的预期（**先说清楚，避免事后挑数**）

按信息量推断，弱标注**应当**不劣于本文：它多出来的正是"人工为这个任务画的标注"，
且该标注同时充当监督与推理提示。因此**预期排序为**
`全监督 0.9235 > C1 框级 ≈ 0.90～0.92 > B2 本文 0.8961 > C2 涂鸦级 ≈ 0.83～0.89`。
**最可能的结局是：本文落在"框级"与"涂鸦级"之间**——即"达到弱标注水平"，而非"超过"。
论文的核心主张据此从一开始就写成"**达到**"，而不是"超过"。

#### C. 公平性红线：目标是把基线做**强**，不是做弱

任何让基线变弱的设计都会使结论失去意义。因此：

1. **同架构**：基干网络 = 与本文**完全相同**的 SAM2.1 base+ 与仅微调的 `sam_mask_decoder`（4.22M）；
2. **同数据**：同样 4000 张原图（EORSSD 1400 / ORSSD 600 / ORSI-4199 2000），同划分、去增强；
3. **同预算**：同 3 epoch、同 AdamW(lr=1e-4)、同 256×256 低分辨率 logits、同候选选择规则
   （按 SAM2 自报分选 3 候选中之一，与推理一致）；
4. **同提示仿真**：C 区也做**提示抖动 + 负样本提示拒绝**（每图等量负样本框、目标为空掩码）——
   即把本文在训练侧的两项设计**也送给基线**，让差异只剩"监督信号"本身；
5. **同推理/评测管线**：同 `predict_repair.py`（C 区不启用 PRISM 算子，只做解码）+ 同 `eval_mllm.py`
   + 同 `eval/metrics.py`，测试集三集齐评。

#### D. 三级构造（标签值一律取 GT，只限制"在哪里产生损失"）

| 变体 | 监督区域（**只有这里产生损失**） | 区域外的标签值 | 标签强度（每图监督像素占比，实测） |
|---|---|---|---|
| **C1 框级** | GT 连通域**外接框内部** | 不监督（loss mask = 0） | 框面积占比（约 5%～25%） |
| **C2 涂鸦级** | 连通域 Zhang-Suen 中轴膨胀后的**涂鸦像素** | 不监督 | 0.04%～1.27%（实测 12 图抽样） |
| C3 图像级（可选） | 全图（仅正类，无位置信息） | 不监督 | 100%（但无位置监督） |

**关键设计（最保守、也最不容易被攻破的一条）**：
C1 的框内标签取 **GT 掩码的精确值**（不是"框内全填 1"）。这等价于给基线一个**框级监督的理想实现**：
监督范围只有框那么大，但框内的值完全正确。真实人工框只会更松、框内背景更多，因此
**这样做只会让基线更强**。论文中据此如实标注一句：

> "box-level baseline with GT-valued labels inside the box — a favourable realisation of box supervision;
> real box annotations would be weaker."

**为什么框外不监督、而不是"框外当背景"**：后者等于白送模型一个额外的强先验（"框外一定不是显著"），
会把框级监督的难度人为拉低。部分交叉熵（PCE）只在标注区域内计算，是这个监督级别的标准做法。

#### E. 推理提示（必须与训练口径逐条对应）

| 变体 | 训练监督 | 推理提示 | 依据 |
|---|---|---|---|
| **C1** | 框内外接框 | **GT 连通域精确框** | 框级标注方法在推理时拿到的就是它自己标的框 |
| **C2** | 涂鸦像素 | 连通域框 **±6% 扰动** | 涂鸦方法需要在推理时给出框；框在训练中**不构成监督**，故允许与训练同口径的扰动 |

- C1 采用精确 GT 框是**对基线最有利**的选择，故无需争议；
- C2 的 ±6% 扰动对应人工画框的松散程度，与本文训练侧的提示仿真口径一致。

#### F. 闸门与执行顺序

1. **探针**：`--limit 200 --epochs 1`，在 **dev 50** 上确认不塌（判据：dev Sα 不低于同条件本文变体
   的 −0.02），再跑全量；
2. **全量**：C1 一档 + C2 三档涂鸦密度（dilate 1/2/3），共 4 次训练；
3. **报告**：C2 **取三档中最好的一档**（对基线最有利），并把三档全部列在补充材料。
   —— 这是唯一一处允许"取最好值"的地方，因为取好值只会让本文的主张更难成立，属于保守做法。

| 被测集 | A2 零训练 | A2+P 零训练 | **源域训练（本次）** | 域内 B2 | 全监督 |
|---|---|---|---|---|---|

**三条结论（全部可写进论文）**：

1. **域偏移代价仅 −0.74 点**（0.8738 vs 域内 0.8811）——把校准器拿到**从未见过的数据集**上，
   几乎不掉分。这比预期好得多（我原本判断"可能掉 3～5 点"，**判断错误，如实记录**）；
2. **跨域保留 92.4% 的域内适配收益**（源域适配 +8.92 点 vs 域内适配 +9.66 点）——
   即"冻结主干 + 4.22M 校准器"学到的是**可迁移的通用显著性校准**，不是数据集特定的记忆；
3. **三条部署线全部成立**：A2 0.7618 → A2+P 0.7845（零训练零参数）→ **0.8738（零标注 + 源域适配，
   新域免标注免重训）** → 0.8811（零标注域内）→ 0.9158（全监督标尺）。
   **第 3 档是本文对"零标注"最强的一条论据**：新域不需要任何标注、甚至不需要它的训练集，
   只要在别的公开数据上适配一次即可用。

**如实记录的边界**：

- 三折下降幅度不均：ORSSD 仅 −0.30、EORSSD −0.55、ORSI-4199 −1.37。ORSI-4199 仍是域偏移
  最敏感的一集（其测试集本身最大、场景最杂），这一条与 §4.7 的失败分析一致；

  沿用 §4.4.6 的"分指标复现性"写法；
- 本实验**不改变**主结果（主结果仍为域内 0.8961，两种子平均）；跨域 0.8738 是**附加能力证据**。

1. **机制成立且稳健**：只用训练集自己的提示分布（完全不接触测试集统计），相对 B2 拿到

2. **但论文报告的 +1.49 点中含有约 0.46 点的测试集优势**：
