# MGRQ-Net I22｜候选查询构造器报告

## 1. 执行结论

I22 已完成并通过验收（`PASSED`）。本阶段实现了默认256维候选查询构造器，将以下五类信息融合为供后续查询解码器使用的统一表示：

1. 256维SAM2 RoI视觉特征；
2. I21冻结的512维CLIP文本特征；
3. `[0,1000]`候选框几何特征；
4. DeepSeek显著性置信度；
5. D16策略派生的查询类型嵌入。

本阶段没有调用DeepSeek API，也没有启动模型训练。

## 2. 模块接口

### 2.1 输入

| 输入 | 张量形状 | 说明 |
|---|---|---|
| SAM2特征 | `[B,256,Hf,Wf]` | 默认作为冻结输入，不回传梯度 |
| 候选框 | `[B,N,4]` | `[x0,y0,x1,y1]`，坐标范围`[0,1000]` |
| 文本特征 | `[B,N,512]` | 来自I21冻结CLIP缓存，不回传梯度 |
| 置信度 | `[B,N]` | 范围`[0,1]` |
| 查询类型 | `[B,N]` | 5类离散嵌入 |
| 有效位 | `[B,N]` | 区分有效候选和批内补齐槽 |
| 原图尺寸 | `[B,2]` | 高、宽，用于处理不同尺寸和批内padding |

### 2.2 输出

| 输出 | 张量形状 | 说明 |
|---|---|---|
| 候选查询 | `[B,N,256]` | 后续解码器的统一查询表示 |
| 修复后候选框 | `[B,N,4]` | 可追踪的规范化框 |
| 框修复标记 | `[B,N]` | 裁剪、坐标重排、退化扩展的位标志 |
| RoI特征 | `[B,N,256]` | 3×3双线性采样后平均池化 |

无候选时返回`[B,0,256]`，而不是制造伪查询；批内补齐槽的查询和RoI特征严格置零。

## 3. 具体融合结构

### 3.1 RoI视觉分支

候选框先根据每张图的真实尺寸和批内padding尺寸映射到SAM2特征图，再在框内执行3×3双线性网格采样和平均池化，得到256维视觉向量。该实现不依赖固定图像分辨率。

### 3.2 文本与结构分支

- 视觉向量：线性投影`256→256`；
- 文本向量：线性投影`512→256`；
- 框几何：使用`x0,y0,x1,y1,cx,cy,w,h`八维表示，经两层MLP映射到256维；
- 置信度：经`1→64→256`的MLP映射；
- 查询类型：使用5类、256维可学习嵌入。

五个256维向量拼接为1280维，经`LayerNorm → Linear(1280,512) → GELU → Linear(512,256) → LayerNorm`输出最终查询。当前冻结配置的dropout为0，便于模块测试与确定性复现。

可训练参数共1,073,536个。SAM2特征和CLIP文本向量默认在入口显式`detach`，只训练I22内部投影层、类型嵌入和融合层。

## 4. 查询类型协议

I22直接复用D16冻结的置信度入口：

| 类型ID | 条件 | 语义 |
|---:|---|---|
| 0 | 显著候选且置信度≥0.8 | 可信正查询 |
| 1 | 显著候选且0.6≤置信度<0.8 | 不确定查询 |
| 2 | 显著候选且置信度<0.6 | 低置信候选，不进入可信正池 |
| 3 | 干扰项 | 软负先验，不直接作为硬背景 |
| 4 | 解析缺失或无候选 | 明确回退查询 |

## 5. 候选框修复协议

为防止几何错误传播到RoI采样，按固定顺序处理候选框：

1. 坐标裁剪到`[0,1000]`；
2. 逆序坐标按最小值/最大值重排；
3. 宽或高不足1个归一化坐标单位时，以中心为基准扩展到最小宽高1；
4. NaN或Inf不做静默修复，直接拒绝。

每种修复均写入位标志：1表示裁剪、2表示重排、4表示退化扩展，可以组合记录。该规则只保障数值与几何合法性，不把明显错误框重新解释为正确语义框。

## 6. 测试与验收

### 6.1 单元测试

9/9项通过，覆盖：

- 不同图像尺寸；
- 空候选；
- 1个候选；
- 5个候选；
- padding候选严格置零；
- 越界与逆序框修复；
- 退化框扩展；
- 5类查询类型阈值；
- 冻结输入与可训练层梯度边界；
- 非有限坐标拒绝。

### 6.2 真实缓存冒烟验收

从D14与I21选择以下四类真实记录：

| 记录 | 类型 | 候选数 |
|---|---|---:|
| `EORSSD/train/0569` | 有效解析 | 1 |
| `EORSSD/train/0106` | 有效解析 | 5 |
| `ORSI4199/train/1044` | 解析缺失回退 | 1 |
| `EORSSD/train/0402` | 无候选回退 | 1 |

验证使用真实候选框和I21文本向量，并以不同空间尺寸的合成256维特征图模拟冻结SAM2输出。结果如下：

- 输入视觉特征：`[4,256,32,32]`；
- 批内候选框：`[4,5,4]`；
- 文本特征：`[4,5,512]`；
- 输出查询：`[4,5,256]`；
- 有效查询：8；
- NaN/Inf：0；
- padding查询非零：0；
- SAM2输入梯度：无；
- CLIP输入梯度：无；
- 可训练参数梯度：21/21个参数张量存在且有限。

此验收验证的是I22接口和融合逻辑，并不声称已完成真实SAM2端到端训练；真实编码器接入与任务性能将在后续模型组装和消融阶段验证。
