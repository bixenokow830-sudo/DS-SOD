| 环节 | v2 纯几何（已跑完，降级为消融） | **v2.1-Hybrid（新主线）** |
|------|------------------------------|--------------------------|

**关键设计**：MLLM 仍只负责"看+判断+定位"（它的强项，SaliLLM 已证明其定位精度超 SOTA），
像素级边界交给 SAM2（它的强项）。两者解耦，各自做最擅长的事。

### H0｜环境与资产准备（0.5 天，$0）

**H0-1 安装 SAM2 并验证推理**
- 拉取 facebookresearch/sam2，下载 `sam2.1_hiera_base_plus` 权重（首选）与 `large`（备选）；
- 单图验证：给定 box 提示 → 输出掩码，确认显存峰值与延迟（记录到效率表）。

**H0-2 性能基准**
- 单图编码延迟、单提示解码延迟、batch 吞吐、显存峰值；
- 判定：2999 张全量推理能否在 <30 分钟完成（预期可以）。

**H0-3 提示词提取器 `scripts/bank_to_prompts.py`**
- 从 `mask_bank.json` 的 `pass2_clean` 提取 SAM2 提示：
  - polygon → **取包围盒**（保留 category/confidence）；
  - box → 原样；
  - point → 点提示（可同时给一个小框）；
- 输出 `banks/sam2_prompts.json`（与掩码库同结构，便于复用评测脚本）。

**H0-4 冒烟测试**
- dev 50 张跑通"提示 → SAM2 → 掩码 → 四指标"，与纯几何版对比；
- 产物：`runs/mllm/hybrid_smoke/`。

**审核点 ①（H0 后）**：冒烟是否跑通、显存是否够、单图延迟是否可接受。

- **若不达标** → 依次尝试：① 换 `sam2.1_hiera_large`；② 多 mask 候选 + MLLM confidence 重排；
  ③ 加 point 提示；④ 仍不行 → 触发预案 R3（见第 4 章）。

### H3｜可选增强（1.5～2 天，$5～18）

**H3-1 SelfCheck 闭环（R1，～$8）**：在 Hybrid 掩码上渲染叠加图 → 回喂 DeepSeek
→ 修正框/点 → 重新 SAM2 解码。验证"语义自修正对像素级方法的增益"。

**H3-2 多候选 mask 筛选**：SAM2 每提示返回 3 个候选 mask，用
（a）SAM2 自身 predicted IoU、（b）MLLM 的 confidence/category、（c）二者融合 打分选择。
**这是本文最可能的方法创新点**（把 MLLM 的语义置信度用于掩码级选择）。

**H3-3 跨 MLLM 消融（可选，$3～5）**：固定管线，换提示词来源模型
（Qwen2.5-VL / Gemini），100 张子集，回答"是模型差异还是模态差异"——直接回应用户观察到的
"Gemini 一张对话就出好图"现象，也是论文的可扩展性论据。

**H3-4 输出模态消融（$0，纯本地）**：同一 DeepSeek，比较
① 多边形坐标（现状）② 低分辨率栅格矩阵文本（如 32×32 的 0/1 矩阵）③ 框提示+SAM2。
量化"输出空间决定精度上限"这一原创论点。

**H3-5 生成式草稿 + SAM2 精修（～1 天，$0 或 ～$3，回答"换生图模型会不会更好"）**

> 动机：Gemini 一张对话就出精细掩码（像素空间生成），但生成式输出有"二值化/随机性/无置信度"
> 三伤。本实验把生成模型降级为**草稿来源**，由 SAM2 精修，各取所长。

```
图像 → 生成式模型 → 草稿掩码（二值化）→ 作为提示喂 SAM2 → soft 掩码 → 评测
```

- **路线 A（本地、零 API、可复现，首选）**：DeepSeek 开源统一多模态模型 **Janus-Pro**
  本地部署（1B 稳跑 8GB，7B 需量化）。提示词："生成一张灰度图，显著目标为白色、背景为黑色"。
  输出 384×384 草稿 → 上采样 → 阈值二值化 → **连通域 → 框/点提示**（而非直接当掩码，
  规避其低分辨率边界不可靠）→ SAM2 精修。
- **路线 B（API，效果最好但不可本地复现）**：Gemini 2.5 Flash Image / gpt-image-1，
  同提示词，～$0.03/张，100 张子集 ≈ $3。

**决策门（H3-5 后，并入决策门②）**：
- 若草稿提示的 Sα 比 Hybrid-B（框提示）提升 ≥2pt 且接近上界（GT 框）→ 升级为论文
  "像素空间草稿先验"模块（新增图/消融）；
- 否则作为 limitation 素材（"生成式掩码视觉更美但指标不占优，因 SOD 指标需要置信度图"）。

**风险**：Janus-Pro 分辨率低、对复杂遥感场景可能画不准 → 草稿只当"区域发现"
（用其连通域做框/点提示），不信任其像素边界——这正是"SAM2 精修"存在的意义。
